Obsidian 자동 백업

수집한 X 북마크와 Threads 저장 게시물을 로컬 API로 볼트에 보관합니다.

1. Obsidian 연결

저장할 볼트의 Local REST API 설정에 표시된 주소와 API 키를 입력하세요.

HTTPS 인증서가 신뢰되어 있어야 합니다. 인증서 오류는 Obsidian 플러그인 설정의 안내에 따라 해결하세요. HTTP는 플러그인에서 명시적으로 활성화한 경우만 사용합니다.

이 Chrome 프로필의 확장 프로그램 로컬 저장소에 보관합니다. X·Threads 페이지나 백업 노트에 포함하지 않으며 별도 암호화 저장은 아닙니다. 키를 채팅에 붙여넣지 마세요.

raw/ 폴더도 Git·클라우드에 동기화될 수 있습니다. 비공개 북마크를 공개 저장소에 올리지 않도록 별도로 제외하세요.

연결 설정을 불러오고 있습니다.

API 상태 페이지 열기 · API 키 없이 서버·인증서 상태를 확인합니다.

HTTPS 인증서 확인 방법

API 상태 페이지에 NET::ERR_CERT_AUTHORITY_INVALID가 표시되면, Obsidian의 Local REST API 설정에서 발급한 CA 인증서를 신뢰 등록해야 합니다.

macOS에서는 해당 CA 인증서를 키체인 접근의 로그인 키체인에 추가하고, 인증서를 열어 「신뢰 → 이 인증서 사용 시 → 항상 신뢰」로 설정하세요. 이후 Chrome을 다시 시작하고 연결을 확인하세요.

이 플러그인이 발급한 인증서만 사용하세요. 확장 프로그램은 인증서 검증을 끄거나 HTTP로 자동 전환하지 않습니다.

2. 자동 백업

북마크 원문과 수집된 댓글·대댓글은 하나의 Markdown 묶음으로 저장합니다. 북마크 목록에는 댓글 본문이 없으므로 원문을 열고 스크롤하거나 답글 더 보기를 펼쳐 주세요. 나중에 수집된 댓글도 원문과 함께 새 묶음으로 백업합니다. 미로드·삭제·비공개 댓글의 전체 수집은 보장하지 않습니다.

Threads의 /saved 목록에서 로드된 게시물을 고유 링크별로 자동 수집합니다. 기존 저장 폴더 아래 threads/에 분리해서 저장하며 X 파일과 충돌하지 않습니다. 짧은 글·사진 전용 글도 포함합니다. 접힌 본문은 원문에서 더 보기를 펼쳐 주세요. 댓글은 명시적인 답글 대상 링크가 확인되는 경우에만 원문과 묶습니다. 모든 댓글·미로드 게시물 수집을 보장하지 않습니다. 아래 자동 수집을 켜면 저장 목록을 주기적으로 열어 스크롤하며, 그 밖의 추가 API 요청은 하지 않습니다.

YouTube 좋아요 목록(재생목록 LL)에 로드된 영상을 영상별로 자동 수집합니다. 기존 저장 폴더 아래 youtube/에 분리해서 저장합니다. 제목·채널·길이·링크 같은 메타데이터만 저장하며 영상 파일은 받지 않습니다. 이 Chrome 프로필에서 YouTube에 로그인되어 있어야 하고, 좋아요를 누른 날짜는 YouTube가 표시하지 않아 기록되지 않습니다.

처음 켜면 열려 있는 X·Threads·YouTube 탭의 기존 수집 데이터도 대기열에 넣습니다. 이후 수집한 게시물은 자동 추가됩니다. Obsidian이 닫히면 기다렸다 재시도합니다. Chrome 종료·절전 중에는 처리하지 않습니다.

3. 자동 수집

설정한 주기마다 X 북마크와, 위에서 백업을 켠 Threads 저장 목록·YouTube 좋아요 목록을 비활성 탭으로 열어 새 항목이 없을 때까지 스크롤한 뒤 탭을 닫습니다. 이전에 수집한 항목이 나오면 그 자리에서 멈춥니다. 백업을 끈 목록은 열지 않습니다.

자동 수집 상태를 불러오고 있습니다.

X·Threads·YouTube에 로그인된 상태여야 합니다. Chrome이 실행 중일 때만 동작하며, 수집한 항목은 위 자동 백업 설정에 따라 Obsidian으로 보냅니다. Obsidian이 꺼져 있으면 대기열에 보관했다가 연결되면 저장하고, 연결이 1시간 넘게 끊기면 알림을 표시합니다.

백업 상태

상태를 불러오고 있습니다.

같은 원문·댓글 구성은 중복 저장하지 않습니다. 댓글 추가 또는 내용 변경 시 전체 묶음을 revisions/에 저장합니다. 미디어는 URL만 보관하며 DM·팔로워 목록·전체 DB 덤프는 포함하지 않습니다. 볼트에서 삭제한 백업을 복구하려면 저장 파일 다시 확인을 누르세요.

API 키가 연결된 볼트에만 저장합니다. 저장 위치·키를 바꾸면 자동 백업을 다시 켜야 합니다.
