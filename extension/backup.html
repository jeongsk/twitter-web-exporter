Obsidian 자동 백업

수집한 X 게시물을 로컬 API를 통해 볼트에 보관합니다.

1. Obsidian 연결

저장할 볼트의 Local REST API 설정에 표시된 주소와 API 키를 입력하세요.

HTTPS 인증서가 신뢰되어 있어야 합니다. 인증서 오류는 Obsidian 플러그인 설정의 안내에 따라 해결하세요. HTTP는 플러그인에서 명시적으로 활성화한 경우만 사용합니다.

이 Chrome 프로필의 확장 프로그램 로컬 저장소에 보관합니다. X 페이지나 백업 노트에 포함하지 않으며 별도 암호화 저장은 아닙니다. 키를 채팅에 붙여넣지 마세요.

raw/ 폴더도 Git·클라우드에 동기화될 수 있습니다. 비공개 북마크를 공개 저장소에 올리지 않도록 별도로 제외하세요.

2. 자동 백업

처음 켜면 열려 있는 X 탭의 기존 수집 데이터도 대기열에 넣습니다. 이후 수집한 게시물은 자동 추가됩니다. Obsidian이 닫히면 기다렸다 재시도합니다. Chrome 종료·절전 중에는 처리하지 않습니다.

백업 상태

상태를 불러오고 있습니다.

동일 ID·본문은 중복 저장하지 않습니다. 내용 변경 시 revisions/에 저장합니다. 미디어는 URL만 보관하며 DM·팔로워 목록·전체 DB 덤프는 포함하지 않습니다. 볼트에서 삭제한 백업을 복구하려면 저장 파일 다시 확인을 누르세요.

API 키가 연결된 볼트에만 저장합니다. 저장 위치·키를 바꾸면 자동 백업을 다시 켜야 합니다.
